# AP Debate Motion Generator

A static web tool that draws Asian Parliamentary debate motions 
from a curated bank. filterable by category and difficulty.

**Live site:** https://keprientojunindo02-lgtm.github.io/ap-debate-motion/

## Built with
Vanilla HTML, CSS, and JavaScript – no frameworks, no backend.

## Features
- 9 motion categories, 3 difficulty tiers (Novice/Intermediate/Open)
- Session-based history ("docket") of drawn motions
- One-click copy to clipboard
